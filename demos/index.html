这十二张是怎么保证"真的有品味"

审美常被当作无法验证的东西。这个项目把它拆成了可执行的参数与可判定的断言： 先定情绪（读者该感受到什么，一个词），再选 1 主 + 1 辅风格基因， 然后把五个基因位翻译成 CSS 变量，最后用程序检查有没有守住纪律。

所以每张作品都附带两样东西：一段写在 HTML 注释里的基因说明（选自哪粒种子、什么激活词、 哪几条纪律），和一份可复现的渲染脚本。你改一个变量，就能看见它偏出基因。

页面底部那一行署名不是水印——它是这套系统产出的证据链的一部分： 谁生成、用哪个模型、什么时间、什么风格基因。

自己跑一遍（约 40 秒）

# 1. 字体子集化（仓库不带 40MB 源字体，只带 1.5MB 子集）
python3 demos/_src/build_fonts.py

# 2. 逐张实时渲染 —— 真实 Chromium、2× 像素比、无损 WebP
python3 demos/_src/render_shots.py

# 3. 两道质检闸门
python3 demos/_src/qa_layout.py   # 布局：溢出 / 越界 / 遮挡 / 对比度
python3 demos/_src/qa_style.py    # 风格：亮度 / 暗部 / 留白 / 色相 / 饱和度

依赖：playwright + Chromium · fonttools + brotli · Pillow
渲染环境：headless Chromium 143，字体全部本地内嵌，断网也能复现同样的图
字体许可：Noto Serif／Sans SC、Playfair Display、Cinzel、Cormorant Garamond、EB Garamond、 Libre Baskerville、Marcellus、Italiana、Yeseva One、Oswald、Inter（SIL OFL）· Archivo Black、Bebas Neue（SIL OFL）· JetBrains Mono（Apache-2.0）
